# 兔兔躲貓貓 (Bunny Hide & Seek · 100 隻統一繪本兔兔正式版) — GitHub Pages 發佈包

## 2 分鐘上架步驟：
1. 在 GitHub 建立新 Repository（例如 `bunny-hide-and-seek`）。
2. 將此資料夾內嘅 `index.html`、`assets/`（143 張手繪圖）同 `audio/` 全部上傳到 Repository 根目錄。
3. 去 Repository 的 Settings → Pages → Source 選 `Deploy from a branch` → `main` / `(root)` → Save。
4. 等 1 分鐘即可獲得網址 `https://<你的帳號>.github.io/bunny-hide-and-seek/`，直接 Send 俾朋友同小朋友玩！
